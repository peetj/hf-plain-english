Privacy and network use

This extension is designed to explain public Hugging Face model pages without tracking you.

  • When a model page is open, it sends the model address to Hugging Face's public API to fetch public metadata, file names, and the model card.
  • Model Match searches Hugging Face using the filters you choose, such as task, format, quantisation, downloads, or likes.
  • The Ask a Question helper runs locally from extension data and the current page facts. It does not contact a chatbot service in V1.
  • Your hardware profile and Model Match choices are stored in Chrome storage on this browser. No analytics are included.
