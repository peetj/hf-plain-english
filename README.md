# Hugging Face for Newbies

A Chrome extension that helps AI learners understand Hugging Face model pages in plain English.

## V1 objective

Open a public Hugging Face model page and explain:

- what the model is;
- what it can do;
- how large it is;
- whether it is likely to run on the user's computer;
- which files are relevant;
- whether to use LM Studio, Ollama, or Python;
- important licence and safety information.

## Initial technology

- Chrome Extension Manifest V3
- Plain HTML, CSS, and JavaScript
- Hugging Face Hub API
- Optional local Ollama explanation service
